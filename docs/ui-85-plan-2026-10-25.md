## Craft pass, 2026-10-29 (branch `ui-craft-polish-2026-10-29`)

From the 2026-10-29 re-score's craft gaps.
- FAQ: five rounded cards became ruled rows (`Faq.astro`).
- Contact: the submit button uses the body face at the `.cta` weight and size.
- About: the tag line wraps two and two on desktop and one, one, two on a phone (`max-width` on
  `.about__tags`).
- Highlights: Lake Forest Country Day School is its own heading and bullet.
- `/easternblok` layout shift, Lighthouse mobile 0.101, desktop 0.049 to 0.137 depending on the
  change. The trace (Lighthouse's own, saved with `--save-assets`) showed the "story" section
  moving 25px when the web fonts loaded. Two causes: `ArchiveLayout`'s `62ch` measures, since a
  `ch` is the width of a "0" in whichever font is active (now `rem`; the header is 42rem because
  its lead paragraph sat on a wrap boundary at 1350px), and system fallback fonts with different
  widths and line heights from Work Sans, Fraunces and JetBrains Mono. `global.css` now has
  `Work Sans Fallback`, `Fraunces Fallback` and `JetBrains Mono Fallback` faces (Arial, Times
  New Roman and Courier New scaled with `size-adjust` and ascent/descent overrides, computed
  with `@capsizecss/metrics`), first in each `--font-*` stack. Archive pages also preload
  `work-sans.woff2` and `fraunces-normal.woff2`; the home page does not, because its mobile LCP
  is too close to its gate to spend bandwidth against the hero photo.
- Result (local `serve`, one run each unless noted): `/easternblok` layout shift 0.101 to 0 on
  mobile and 0.137 to 0 on desktop, performance 100 on both. `/press`, `/easternblok/press`:
  shift 0, performance 100. Home: shift 0 mobile and 0.001 desktop.
- Regression test: `e2e/layout-shift.spec.ts` loads each archive page at 412px and 1350px twice,
  once with the web fonts blocked and once with them, and requires the first section to sit within
  8px. It fails on the old code (27px on three pages) and passes now. An earlier version that
  delayed the fonts and read `layout-shift` entries passed on the old code too, so it was dropped:
  whether the shift happened depended on which side of first paint the fonts landed.
- Not changed, on purpose: press outlet links stay about 32px tall (recorded trade-off in
  `QuoteLedger.astro`).
- Noticed, not part of this pass: home page mobile performance scored 86 today on both the old
  and new code (LCP 3.7s), below the 0.9 gate in `lighthouserc.json`; it scored 89 to 90 on
  2026-10-28. The hero photo is the likely cause. Not investigated.
- Removing the shimmer also removed the headline's continuous motion. That wasn't Doug's call,
  and he isn't decided on it; see "Hero motion: taken out, not decided" in `DESIGN_NOTES.md`.
